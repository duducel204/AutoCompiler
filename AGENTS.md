# AGENTS.md — Agent Governance & Operations Guide

This document defines the rules, principles, and operating standards for AI coding agents working on the **AutoCompiler** repository.

---

## 1. Core Directives

1. **Roadmap Execution Procedure**:
   - All roadmap tasks `J-XXX` **MUST** be executed using the skill/procedure defined in `skills/execute-roadmap-task/SKILL.md`.
   - Before executing a task, read the canonical documents in this exact order:
     1. `docs/PRODUCT_INTENT.md`
     2. `docs/AUTOMATION_GRAMMAR.md`
     3. `docs/BASIC_1_0_COVERAGE.md`
     4. `docs/DECISIONS.md`
     5. `AGENTS.md`
     6. `docs/PRODUCT_ROADMAP.md`

2. **Task-by-Task Sequential Execution**:
   - Agents must execute **one job/task at a time** (e.g., `J-001`).
   - Do **NOT** advance to subsequent tasks (e.g., `J-002`) until the current task's **Definition of Done (DoD)** is fully satisfied and verified.

3. **Strict Compliance with Trust Gate**:
   - Every code or configuration change must pass the project's canonical validation gate (`python3 scripts/trust_gate.py` and `PYTHONPATH=. pytest`).
   - Rule: *Restore invariants, never manufacture green.*

4. **Plan / Apply / Verify Boundary**:
   - Planning and resource discovery must remain read-only.
   - Environment mutations require explicit authorization and post-change verification.

5. **Zero-Token Runtime Execution**:
   - Automation artifacts generated by AutoCompiler must execute deterministically without requiring recurring LLM API calls.

---

## 2. Definition of Done (DoD) Contract

A job `J-xxx` is considered **DONE** only when:
- [ ] All deliverables specified in the job description are completely implemented or documented.
- [ ] No unconfirmed file paths or unauthorized mutations are introduced.
- [ ] `python3 scripts/trust_gate.py` returns `"gate": "PASS"`.
- [ ] `PYTHONPATH=. pytest` passes with 0 failures.
- [ ] A formal **Job Completion Report** using the schema in `skills/execute-roadmap-task/SKILL.md` is generated and delivered to the user.
