# Product Intent — AutoCompiler

## Core Mission
Transform user intention into installed computational capability using logic and free tools already available on the user's machine and cloud free-tiers.

## Non-Negotiable Invariants
1. **Zero Recurring AI Token Cost**: Executed routine automations run 100% deterministically.
2. **Runtime Independence**: Generated automation artifacts survive without AutoCompiler runtime.
3. **Provider Neutrality**: Semantic capabilities (`durable_state`, `messaging`, `http`) are separate from concrete providers (`SQLite`, `PowerShell`, `Python`).
4. **Plan → Authorize → Apply → Verify**: Planning is read-only; environment changes require explicit authorization and post-change verification.
